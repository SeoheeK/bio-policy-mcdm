# etcd (Patroni DCS)

Patroni는 분산 합의 저장소(DCS)가 필요합니다. 온프레미스에서는 **etcd 3노드** 구성이 가장 일반적입니다.

## 권장 노드

- `10.10.21.70` (etcd-1)
- `10.10.21.71` (etcd-2)
- `10.10.21.72` (etcd-3)

## 포트

- Client: `2379/tcp`
- Peer: `2380/tcp`

## 적용

- 각 노드에 `etcd.env`를 맞게 수정 후 `etcd.service`로 실행합니다.
- 방화벽에서 **DB 노드(10.10.21.10/11) → 2379** 접근을 허용해야 합니다.
