- Node-1: `10.10.21.60` (HTTP 6333, gRPC 6334, P2P 6335)

2노드는 운영 가능하지만, 합의/장애 시나리오를 더 안전하게 하려면 **3노드(과반)** 구성이 일반적으로 더 유리합니다.  
이번 설계서는 사용자 요구대로 2노드를 유지합니다.
