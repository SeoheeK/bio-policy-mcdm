# Obsidian Vault (설계서/운영서 관리)

이 저장소는 Obsidian을 이용해 “DB 설계서 + 운영 Runbook + 변경 이력”을 **마크다운으로 일원화**할 수 있도록 Vault 형태의 폴더를 제공합니다.

## 사용 방법

1. 로컬에서 Obsidian 실행
2. **Open folder as vault** 선택
3. 이 저장소의 `obsidian/` 폴더를 Vault로 지정

## 추천 플러그인(선택)

- Templates: 반복 문서 템플릿
- Dataview: 표/쿼리 형태로 문서 메타데이터 집계
- Excalidraw/Canvas: 아키텍처 다이어그램

## 이 저장소와 연동 포인트

- 구현 산출물: `infra/`
- 단계별 결과: `report.csv`
- 구독 필요 사항: `subscription_report.csv`
